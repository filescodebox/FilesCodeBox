# 使用说明

面向日常使用者与站点管理员的功能手册。部署未完成请先读[快速开始](./getting-started)；环境变量细节见[环境变量参考](./environment)。

## 基本概念

| 概念 | 说明 |
|---|---|
| **分享码** | 8 位字母数字串（区分大小写），唯一标识一次分享，如 `4IyC6gZF` |
| **取件码** | 6 位码，匿名寄件（反向收件）场景下访客投递后生成的提取凭证 |
| **完整链接** | `http://你的站点/#/share/<分享码>`，对方点开即达取件页 |
| **取件页** | 打开链接或输入分享码后的页面：无密码直出内容，有密码先验证 |
| **过期时间** | 每次分享必须设定：分钟 / 小时 / 天 / 周 / 月 / 年 / 永久，到期自动失效 |

## 创建分享

站点首页有三个标签页：**文件分享**、**文本分享**、**获取分享**。

![首页 · 获取分享](/screenshots/home-get.png)
*首页 · 获取分享标签页（输入分享码/取件码直达取件）*

### 文本分享

1. 切到「文本分享」，输入内容（上限约 1 万字符）；
2. 设定**过期时间**（数值 + 单位）；
3. 可选项：
   - **访问保护**：开启后设置取件密码，对方须凭密码取件；
   - **自定义取件码**：指定 3-32 位字母/数字/`-`/`_` 作为分享码（默认随机 8 位）；
   - **端到端加密**：加密密钥在**你的浏览器**生成并嵌入分享链接，服务器只存储密文、无法解密——链接丢了内容就找不回，请勿丢失链接中的 `key` 参数；
4. 点击「立即分享」。

### 文件分享

1. 切到「文件分享」，选择**一个或多个**文件（支持多选）；
2. 过期时间 / 访问保护 / 自定义取件码 / 端到端加密 选项与文本分享一致；
3. 点击上传创建。

大文件自动走**分片上传**通道；相同内容的文件重复分享会命中**秒传**，无需重新传输。单文件大小上限由站点配置 `upload.upload_size` 决定（默认 10MB，反代侧 `client_max_body_size` 需同步放开）。

### 分享成功弹窗

创建成功后弹出结果框，三种交付方式任选：

- **8 位码**：把分享码发给对方，对方在首页「获取分享」输入即可；
- **完整链接**：复制直链发给对方，点开即达；
- **二维码**：扫码取件（手机场景最方便）。

![分享成功弹窗（8 位码 / 完整链接 / 二维码）](/screenshots/share-success.png)

## 取件

- **无密码分享**：打开链接（或在取件页输入分享码）→ 文本内容直接显示，文件提供下载按钮；
- **密码分享**：取件页出现密码输入框，输入正确密码后查看；密码错误可重试；
- **多文件分享**：逐文件下载，或一键**打包 zip**；
- **在线预览**：常见图片、视频、音频、文本/代码类文件支持取件页内预览，无需下载。

## 注册用户功能

![登录页](/screenshots/login.png)
*登录页*

![注册页](/screenshots/register.png)
*注册页（开放注册的站点）*

开放注册的站点可在页面注册账号（管理员可在后台关闭注册）。登录后获得以下能力：

- **我的分享**：查看名下全部分享，支持**延期**、删除（软删除，可恢复）、**永久删除**；
- **寄件码（反向收件）**：生成一个投递链接（可限定最大文件数、总体积、有效期），访客凭链接向你投递文件——文件自动落成**你名义下**的分享，并有到件通知；
- **通知中心**：接收系统公告与到件提醒，未读数角标提示；
- **API Token**（`fcb_sk_` 开头）：在「令牌」页创建，用于程序化调用 `/api/v1` 数据面接口（见 [API Token 指南](../reference/api-tokens)）。

登录态为 HttpOnly Cookie（浏览器自动携带，写请求自动附 CSRF 头）；同一账号修改密码或被管理员封禁后，所有已登录会话即时失效。

## 联邦分享（可选）

部署了 p2p 联邦注册中心的站点（Docker Compose 模板与 Helm Chart 均含可选组件）支持**跨站分享**：创建分享时使用高熵自定义取件码（如 `fede2e-xxxxxxxxxxxxxxxx`），其他接入同一注册中心的站点可凭该码解析到来源站点并完成取件——内容始终留在源站，注册中心只存哈希路由。

## API 与自动化

- **OpenAPI 规范**：后端运行时生成 `GET /openapi.json`，可直接导入 Apifox/Postman；
- **API Token**：`Authorization: Bearer fcb_sk_xxx` 调用 `/api/v1` 数据面接口（分享创建/取件/列表等），详见 [API Token 指南](../reference/api-tokens)；
- **MCP（AI 集成）**：`POST /api/v1/mcp` 单端点 JSON-RPC 2.0，管理员认证后可让 AI 助手直接创建/管理分享，详见 [MCP 集成](../reference/mcp)。

## 常见问题

**Q：分享码丢了怎么办？**
分享码是取件唯一凭证（服务端不提供"找回"）。端到端加密分享还须保留链接中的密钥参数，两者皆失内容不可恢复。

**Q：提示上传大小超限？**
站点默认单文件 10MB（`upload.upload_size`）。自建站点可在后台「站点配置」调整，并同步放开反代的 `client_max_body_size`。

**Q：为什么有的文件不能在线预览？**
预览按文件类型支持：图片/视频/音频/文本代码类可预览，其余类型（压缩包、办公文档等）请下载后查看。

**Q：匿名访客能上传吗？**
由站点开关「匿名上传」（`upload.open_upload`）决定，管理员可随时在后台关闭。

**Q：忘记管理员密码？**
`FCB_ADMIN_PASSWORD` 仅在**首次初始化**（数据库中尚无管理员）时生效，之后修改该变量不会改动已有密码。已有实例忘记密码：由运维在数据库中将 `admin` 用户删除后重启实例，系统会按 `FCB_ADMIN_PASSWORD`（未设则 `admin123`，请立即改密）重建管理员。

**Q：局域网/内网无法访问？**
Docker Compose 默认仅本机可访问（安全默认），如需局域网开放请在 `.env` 设 `FCB_API_BIND=0.0.0.0` 后重建，详见[快速开始](./getting-started)。
